Discrete Structures, Fall 2026, RSA project. The maths runs in rsa.cpp (our Part B code), compiled to WebAssembly with wasi-sdk. The page draws the tables itself and checks each final value against the answer from rsa.cpp. The look borrows from the Enigma machine (keys, lampboard, rotors), but the cipher is RSA. The UI was built with help from an AI assistant (Claude), as the bonus rules allow. Fonts: Stardos Stencil, Barlow Condensed and Courier Prime (SIL Open Font License). Voice input uses the browser's Web Speech API.
